## 올리는 법 (GitHub 웹)
1. 이 폴더에서 **Add file → Upload files**
2. 위 이름의 이미지를 끌어다 놓기
3. 브랜치 `claude/prologue-reference-page` 에 **Commit**

확장자가 `.jpg` 등이면 그대로 올리고 알려주세요 — `hub/data.js` 경로만 맞춰드립니다.
