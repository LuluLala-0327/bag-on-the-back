# ACTION CAMERA — 액션 게임 카메라 연출 경우의 수

액션 게임(스페이스마린2 × 스텔라블레이드)의 카메라 연출 경우의 수를 정리한 정보성 사이트.

- **24개 섹션 · 337개 카메라 연출**: 기본 이동부터 전투 · 락온 · 다수전 · 보스전 · 처형 · 쉐이크 · 슬로우 · FOV · 보정 시스템까지
- **레퍼런스 인라인 재생**: 각 연출 그룹의 유튜브 레퍼런스를 클릭하면 사이트 안에서 바로 영상이 재생됨
- **검색**: 상단 검색창에 키워드(예: 락온, 처형, 패링) 입력 시 실시간 필터링
- **디자인**: 흑백 미니멀 타이포그래피, 깔끔한 정보 전달 우선

## 구성
- `index.html` — 사이트 (렌더링 + 검색 + 임베드 플레이어)
- `data.js` — 콘텐츠 데이터 (섹션 / 그룹 / 항목 / 레퍼런스)

## 로컬 실행
정적 파일이라 `index.html`을 브라우저로 열면 됩니다.
```
python3 -m http.server
```
